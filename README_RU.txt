SmoothRide MP: плавные машины в мультиплеере Project Zomboid (B42.21+)

Что делает
- Чужую машину видно с отставанием ~60-100 мс вместо 500+ мс. На 80 км/ч это ~1-2 м вместо 11+ м.
- Пассажира больше не дёргает: машина едет по плавной кривой, построенной по скорости,
  а промахи предсказания сглаживаются, а не телепортируют машину.
- Водитель отправляет положение машины ~30 раз в секунду вместо ~6.
- Если версия игры не подходит, мод сам выключается, и работает обычная синхронизация.

Бесплатно, исходники открыты. Почти весь код пишет нейросеть; подписка на неё, тесты и время — мои.
Если мод сделал игру лучше: https://boosty.to/lrgpp

Установка (нужно у каждого игрока)
1. Должен стоять ZombieBuddy 2.3.4+. Если вы играете на сервере с BetterVehicleDynamics
   или RealVehicleInteriors, он у вас уже есть.
2. Распакуйте папку SmoothRide в %UserProfile%\Zomboid\mods\
   Должно получиться: %UserProfile%\Zomboid\mods\SmoothRide\42\mod.info
3. При первом заходе на сервер ZombieBuddy спросит разрешение на Java-мод SmoothRide. Разрешите.

Мод должен быть и в списке модов сервера (Mods=...;SmoothRide).

Настройки
Файл %UserProfile%\Zomboid\SmoothRide.properties создаётся при первом запуске.
  mode=balanced   по умолчанию
  mode=smooth     максимум плавности, примерно +40 мс задержки
  mode=realtime   минимум задержки, больше предсказания
Чтобы вернуть настройки по умолчанию, удалите файл.

Как проверить, что мод работает
В логе игры %UserProfile%\Zomboid\console.txt есть строки [SmoothRide]:
  "self-test: interpolation override OK"  мод включился
  "driver: ... (30.0/s)"                  вы за рулём, положение уходит 30 раз в секунду
  "vid N: ... delay avg 80 ..."           раз в 30 с: задержка и пинг по чужой машине
Если доступна Lua-консоль (режим отладки), там есть SmoothRide_status()
и SmoothRide_set("mode","smooth").

Живой тест (локальный сервер, водитель и пассажир-наблюдатель, 145 FPS)

    (у настоящей машины 28 м/с²)

  телепортов (резких скачков)                        2           0

Важно
- Мод сделан на 100% с помощью ИИ.
- Он сделан только для игры с другом.
- Проверен только на выделенном сервере. На сервере, созданном из меню игры, не проверялся.
